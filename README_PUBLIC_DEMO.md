# RBAM Controlled Public Demo

Purpose: demonstrate RBAM's commercial value without publishing enabling proprietary implementation details.

## Safe public story
RBAM combines current operational observations with historical context to produce traceable, evidence-governed appraisals.

## Intentionally excluded
- exact scoring rules and weights
- evidence-fusion internals
- recurrence/similarity calculations
- historical retrieval implementation
- proprietary state-transition logic
- bypass/arbitration mechanisms
- learning/update mechanisms
- post-freeze invention details

## Safety boundary
This build is simulation-only and advisory. It has no PLC, SCADA, SIS, ESD, BOP, actuator, or physical equipment integration.

## Deployment recommendation
Deploy this folder as a separate public repository or static site. Keep the private RBAM core repository private. Do not copy proprietary backend code into this demo.
